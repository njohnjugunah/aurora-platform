## OVERVIEW

Aurora Platform consolidates salon operations into one system. This guide covers how staff uses the system for their daily work.

## MAIN WORKFLOWS

### Workflow 1: Book an Appointment

1. Click "New Appointment"
2. Search or create customer
3. Select service (duration, price shown)
4. Select available staff member
5. Pick date and time (calendar shows availability)
6. Add notes (e.g., "customer prefers brown color")
7. Confirm booking
8. Send SMS/email confirmation to customer

### Workflow 2: Process Sale & Payment

1. Create new sale transaction
2. Search and add services/products
3. Apply discount if applicable (loyalty tier discount auto-applied)
4. Select payment method:
   - **Cash**: Print receipt
   - **M-Pesa**: Customer enters PIN, system verifies
5. Deduct inventory automatically
6. Award loyalty points
7. Print receipt

### Workflow 3: View Appointment History

1. Click "Customers"
2. Search customer by name or phone
3. View visit history
4. See loyalty tier and points
5. Add notes for next visit

## COMMON TASKS

**Task 1: Reschedule Appointment**
1. Open appointment
2. Click "Reschedule"
3. Pick new date/time
4. Send confirmation to customer

**Task 2: Process Refund**
1. Open sale
2. Click "Refund"
3. Enter reason
4. Confirm (manager approval required)
5. Refund sent to original payment method

**Task 3: Low Stock Alert**
1. Manager receives alert when product < reorder point
2. Click "Create Purchase Order"
3. Email sent to supplier
4. Update when stock arrives

## TROUBLESHOOTING FOR STAFF

**Q: Payment is stuck in "pending" status**
- Wait 2 minutes for M-Pesa callback
- Refresh page to see updated status
- Contact manager if still pending after 5 minutes

**Q: Appointment shows double-booked**
- Refresh page (browser cache issue)
- If persists, contact manager

**Q: Can't access certain features**
- You may not have permission
- Contact manager to request access

**Q: Receipt won't print**
- Check printer is connected and online
- Try printing again
- Contact IT if issue persists
