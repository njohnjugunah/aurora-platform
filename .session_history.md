## ARCHITECTURE NOTES

### Design Patterns Used

1. **Dependency Injection**: All controllers receive services via constructor
2. **Single Responsibility**: Controllers only handle HTTP concerns
3. **Service Layer**: All business logic delegated to services
4. **Exception Handling**: Specific exceptions for different error types
5. **Logging**: All operations logged for audit trail
6. **Validation**: Input validation before service calls
7. **Error Responses**: Consistent error structure across all endpoints

### Key Decisions

1. **No Direct Repository Access**: Controllers use services only, maintaining clean separation
2. **Pagination Always Included**: All list endpoints support pagination
3. **Consistent Response Format**: All endpoints return success/error/data/meta structure
4. **Audit Logging**: All operations logged for compliance
5. **Soft Deletes**: Delete endpoints mark records as deleted, not removed
